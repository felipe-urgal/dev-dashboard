# Protótipos de interface

Páginas HTML autocontidas, sem build step, usadas para discutir direção visual antes de alterar os componentes Vue de `apps/web`.

Elas **não** entram no bundle e não conversam com a API; os dados são fixos no próprio arquivo.

Para abrir, basta apontar o navegador para o arquivo.

Protótipos cuja proposta já foi implementada devem ser removidos deste diretório. Depois da implementação, a tela real, a documentação correspondente e o PR/issue passam a ser a referência; não existe backlog versionado em `tasks/`.
